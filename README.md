Motor de analytics desenvolvido em Python para análise de eventos em
ambientes de varejo.

O sistema trabalha com eventos de entrada, saída e permanência, permitindo
analisar comportamento, fluxo entre zonas e padrões de visita.

### Principais conceitos

- Estruturas de Dados
- Algoritmos
- Top-K
- KMP
- Bubble Sort
- Merge Sort
- Benchmark
- Análise temporal
- Análise de fluxo

🔗 [Ver projeto](https://github.com/Joaogabrielgabry/motorAnalytics)

## 🧠 NutriDataLab

Pipeline de Machine Learning aplicado à análise nutricional.

O projeto utiliza dados para realizar diferentes tipos de análise,
incluindo segmentação, classificação e regressão.

### Funcionalidades

- 👥 Clustering de pacientes
- ✅ Classificação de sucesso de dietas
- 📉 Regressão para estimativa de perda de peso
- 🧪 Feature Engineering
- 📊 Avaliação de modelos
- 🔬 Cross-validation
- 📈 Visualização de dados

### Tecnologias

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
